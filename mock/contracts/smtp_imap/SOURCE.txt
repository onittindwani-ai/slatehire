Protocols, not a web API: SMTP (RFC 5321), message format (RFC 5322), IMAP4rev1 (RFC 3501). There is no OpenAPI or other machine readable contract.
The adapter uses Python's standard library clients (smtplib, imaplib, email), which implement these RFCs, so the wire format is not written by hand here.
What is tested: the adapter against the local fake servers in mock/mail_servers.py (apps/api/tests/test_adapters.py), and that a message it builds has the RFC 5322 header fields (see mock/tests/test_contracts.py).
RFC 3501 text was fetched on 2026-11-23 (https://www.rfc-editor.org/rfc/rfc3501) but the tool returned only the first 100,000 of 254,203 characters, so no IMAP example was saved. Never run against a real mail host.
