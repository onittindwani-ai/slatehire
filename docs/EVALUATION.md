The numbers that matter most:
- **Identity leaks after redaction.** The first run without a known name left <!--n:eval.independent.a_first.leaked-->50<!--/n--> of <!--n:eval.independent.a_first.planted-->627<!--/n--> planted items readable on set A (<!--n:eval.independent.a_first.leak_percent-->8.0<!--/n--> percent): most were the name of the reference person on a line such as "Reference: name", then family and belief lines and a bracketed photo note. On set B, which ran after those fixes, <!--n:eval.independent.b_first.leaked-->30<!--/n--> of <!--n:eval.independent.b_first.planted-->633<!--/n--> leaked (<!--n:eval.independent.b_first.leak_percent-->4.7<!--/n--> percent): street addresses written outside the US and UK style and school names in other languages. After general patterns for those, both sets read 0 leaks, but neither is held out any more, so 0 is a regression check, not a claim. A stricter reading that also counts a readable fragment (a name word, the start of an email, seven digits of a phone) still shows a few name fragments (<!--n:eval.independent.a_rerun.fragments-->4<!--/n--> on A, <!--n:eval.independent.b_rerun.fragments-->1<!--/n--> on B). With the name known from the application form the first runs leaked <!--n:eval.independent.a_first.known_leaked-->20<!--/n--> (A) and <!--n:eval.independent.b_first.known_leaked-->30<!--/n--> (B).
- **Evidence quote validity.** 100 percent on every run, by code: a quote is shown only when it is found again in the redacted text. This is a property of the check, not of the scorer's judgement: a wrong level with a real quote still passes.
- **Score changes from injected instructions.** No resume scored higher with an instruction line than without it, in either set. Three generic instruction lines appended to all 60 resumes of each set raised no total. The first run flagged only 3 of the 6 instruction lines of set A, because the word "the" had been taken for a name in three resumes and redacted, so the line no longer matched (a real bug, found while reading why, fixed). A keyword line appended to every resume raised <!--n:eval.independent.a_first.kw_probe_rose-->54<!--/n--> of 60 totals on the first run of set A, because a line of repeated rubric words was read as work. It now raises none: a skills line, a run of short items or repeated words counts as no evidence.

Plain readings and weaknesses:
- The rules scorer is weak at the exact level. On set A it matched the key exactly <!--n:eval.independent.a_first.exact-->0.233<!--/n--> of the time on the first run: it called most vague mentions and many concrete duties "no evidence" because the resume used other words than the rubric lists. Changes made from general English (word forms, a multi word term matches when all its words are present, cues for helping, doing, a number or result, ownership) lifted both sets, but those are re runs on set A, not held out. Set B, the clean number, was <!--n:eval.independent.b_first.exact-->0.37<!--/n--> exact and <!--n:eval.independent.b_first.within_one-->0.743<!--/n--> within one. On set B 19 criteria with no evidence in the key were still read as level 3 or more.
- Level 4 is often read as 5 and level 2 as no evidence. Do not rank or reject people by the number.
- The old self written set looked better (0.485 exact on its first run) because the same person wrote the rules and the labels. Its numbers after the changes are exact <!--n:eval.scoring_now.level_exact-->0.35<!--/n-->, within one <!--n:eval.scoring_now.level_within_one-->0.848<!--/n--> and rank correlation <!--n:eval.scoring_now.spearman-->0.849<!--/n--> (its labels follow the old rules, so exact fell while the rest held).
- Fairness arithmetic was exact on 8 of 8 cases in set A and 6 of 8 in set B. The two B cases differ only in a reading: the key names no reference group when just one group is assessed, and the system names that group as the reference. Rates, ratios, flags and the indicator word matched in all 16 cases.
- Disclosure: before the set A run only key names and types were read. After it, counts, the shape of leaked items and the lines of leaked reference names were read, so the set A redaction and scoring changes were made after seeing set A formats. Set B was run after those changes and not read before its run. The set B changes (street and school patterns) were made without reading set B items, from general knowledge, after its first run. The scoring thresholds were not changed after the set B run.

## The model path (UNVERIFIED live)
`SCORER=model` with `LLM_BACKEND=fixture` or `anthropic` scores one criterion per call from the redacted resume only, in an untrusted data block, and the code finds the evidence quote again, rejects a quote that is not in the resume, counts a keyword line as no evidence and adds the total up. It has <!--n:model.tests-->24<!--/n--> tests against a local mock server (request shape, hostile resume text, a model that answers with a quote that is not in the resume, a model that adds a decision field, kill switch, call budget, no network when the backend is unset even if a key is in the environment) and <!--n:model.fixtures-->40<!--/n--> recorded fixtures made from that mock server, not from a real model. How a real model scores real resumes is unknown: run `tools/eval_independent.py` with a real key on your own sample set before you trust it.

## Vendor contract tests
<!--n:model.contract_tests-->7<!--/n--> test functions (11 runs, one is repeated for each vendor's facts file) in `mock/tests/test_contracts.py` check the Cal.com, Google Calendar, Ashby and Greenhouse adapters against page text excerpts saved in `mock/contracts/` (URL and date in each header). No machine readable spec was fetched for any vendor; Workable's public pages could not be read at all. Found while reading: Greenhouse's page says attachments moved to the application level in 2020 and that Harvest v1 and v2 end on 2026-08-31, so the candidate attachment reading and the whole adapter need a check against Harvest v3 before use.

## Known miss
A keyword stuffed resume written as full sentences can still score. Quotes are checked, so it shows, but a person must read.

## Fairness
The page prints exact fractions and compares groups of 10 or more people. It cannot say a process is fair or lawful. See [limits](14-LIMITS-AND-HONEST-NOTES.md).
